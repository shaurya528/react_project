# Todo List App (React)

A simple Todo List application built using React to practice basic concepts.

## Features
- Add a new todo
- Delete a todo
- Mark todo as completed
- Uses React Hooks (useState)

## Tech Stack
- React
- JavaScript
- HTML
- CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Purpose
This project is part of my React basics learning journey.
